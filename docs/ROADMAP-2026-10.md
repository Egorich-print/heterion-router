## 0. Как читать

Обозначения: **E** — оценка (S ≈ ≤0.5 дня, M ≈ 1–3 дня, L ≈ 1–2 недели),
**Р** — риск регрессии (S/M/L), **ID** из отчётов: `W-` слабые места
(`01-weaknesses.md`), `D-`/`S-`/`R-`/`B-` дубликаты и реорганизация
(`04`, `05`), `M-` паритет с OmniRoute (`02`), gap-строки — `03`.

Каждый пункт DoD — проверяемая команда, а не «сделать и проверить глазами».
Принцип миссии сохраняется: **красный тест → фикс → зелёный гейт**.

## 1. Что это за проект (фильтр «in scope»)

Локальный, однопользовательский, однобинарный OpenAI-совместимый шлюз в
`~/.heterion-router`, с дашбордом и Tauri-оболочкой. Решения, принимавшиеся в
аудите, в одной строке: **tenancy — нет, биллинг — нет, ML-модели в бинарнике —
нет, documents/RAG-индекс — не наша граница**.

Отсюда 3 из 4 «мы хуже Future-AGI» строк сознательно не в работе:
multi-tenant RBAC, SAML/SCIM/SOC2, usage-based billing с балансами — они
бессмысленны для процесса, который слушает `127.0.0.1` и держит ключи одного
оператора (`03-futureagi-parity.md` §Part 3, строки P3 «no»).

**Замороженные контракты** (`AGENTS.md`) — их нельзя ломать ни в одной фазе:
`STATIC_SALT` + префикс `enc:v1:`; `HETERION_ROUTER_*` → `OMNIROUTE_*`;
`~/.heterion-router` → `~/.omniroute`; порты 20128/20129; keyless-бэкенд не шлёт
`Authorization`; **4xx провайдера не роняет breaker**.

## 13. Порядок и гейты

```
M0 (закоммитить) ──┬──> M1 (честные данные) ──> M3 (деньги)
                   │         └──> M2 (протоколы)
                   └──> M4 (роутинг) ──> M5 (наблюдаемость)
                              └──> M6 (производительность) ──> M7 (структура)
```

Жёсткие зависимости: M3 требует `cost_usd` в ответе из M1; `least-latency`
требует перцентилей из X-2; `semantic`-кэш требует `/v1/embeddings` из M2;
всё после M0 невоспроизводимо без него.

**Гейт на каждой фазе** (тот же, что CI, ADR-012):

```sh
scripts/ci/check.sh                                        # fmt + clippy -D warnings + test
cargo fmt --manifest-path desktop/src-tauri/Cargo.toml -- --check
```

Порог тестов на фазу: **+15 на M1, +20 на M2, +25 на M3, +15 на M4, +15 на M5,
+10 на M6** — и ни одного нового теста без красного прогона на откаченном
фиксе. Провал любого гейта останавливает фазу, а не «докладывается на
следующей».

## 14. Stop / go

**Go**, если: гейт зелёный, у каждого пункта фазы есть красный-доказанный тест,
ни один замороженный контракт из `AGENTS.md` не сломан, версии в `STATUS.md`
пересчитаны командой, а не по памяти.

**Stop и эскалация**, если: требуется миграция схемы, меняющая `enc:v1:` или
`STATIC_SALT`; требуется решение владельца из §11; новая зависимость без
записанной альтернативы; правка затрагивает live-БД `~/.heterion-router`.
