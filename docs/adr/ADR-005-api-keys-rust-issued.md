# ADR-005. API-ключи выпускаются в Rust в JS-форме

> Дата: 2026-09-18 · Статус: accepted

## Контекст

Ключи выпускал JS-сервер. После отказа от Node шлюзу нужно было уметь выдавать
и отзывать ключи самому, не ломая совместимость с уже существующими строками в
`api_keys`.

## Решение

Rust генерирует ключ **в той же форме**, что JS: `sk-` + 32 hex, `key_prefix`
(11 символов) для маскированного показа, `key_hash` = sha256, manage-скоупы,
UUID v4 в `id`. Такой ключ работает и в старой кодовой базе, если она
поднимется из архива.

Проверка ключа в Rust соблюдает kill-switches, которые раньше игнорировались:
`revoked_at IS NULL`, `is_banned = 0`, `is_active = 1`, срок не истёк. Срок
парсится в Rust, потому что таблица содержит два формата timestamp.

Секрет возвращается ровно один раз при создании; списки отдают только префикс.

## Следствия

- Отзыв действует немедленно — аутентификация читает таблицу на каждый запрос.
- `enc:v1:`-строки перечисляются как непригодные (Rust не умеет их расшифровать),
  а не молча ломаются.
