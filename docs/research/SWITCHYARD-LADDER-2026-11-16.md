# Switchyard: лестница capabilities, доверие и ротация — замер 2026-11-16

## Что менялось

`auto` перестал быть «списком из семи моделей + плоский хвост». Порядок пула
стал **считаться** из трёх независимых слоёв:

| слой | вопрос | источник |
|---|---|---|
| capabilities | какая модель **лучше подходит** | `model_capabilities` + `model_capability_overrides` (research) |
| доверие | отдаёт ли её **эта площадка** | `call_logs` (`status=200`), измеренный `real_context`, курируемая лестница |
| ротация | кто отвечает **сейчас** | счётчик обслуживаний (45 с) и провалов (120 с) |

Формула приоритета:

```
приоритет = класс + контекст + инструменты + vision + reasoning
класс:      frontier 240 | fast 140 | fallback 60
контекст:   0 при ≤32k, дальше 20 очков за удвоение, максимум 60
инструменты: 25 за нативный tool head
vision:     15
reasoning:  20
```

Недоказанная модель получает приоритет × 0.1 и тем самым встаёт **ниже**
любой модели, с которой роутер уже говорил. Провал (400/401/404/422/5xx)
уводит модель вниз на 120 с — временно, без штрафа quality-трекера, то есть
без 15-минутной пробации (контракт I-12) и без влияния на соседние модели
провайдера.

## Данные

Research собран по семействам через Exa-поиск (субагенты, `docs/research/ladder/*.jsonl`):
347 семейств в 4 бакетах (A — Qwen/MiniMax/GLM/Kimi, B — open-weight, C —
OpenAI/Anthropic/xAI/mistral, D — Gemini и веб-платформы). Слияние:
`scripts/apply_model_capabilities.py` → **404 пары «провайдер/модель»** в
`model_capabilities` + `tier` в `model_capability_overrides` (бэкап БД:
`storage.sqlite.bak-capabilities`).

Покрытие: из 415 живых записей каталога capability-данные есть у **404**
реальных моделей; без них остались 11 — все виртуальные комбо-имена
(`auto`, `main-262k`, `google`, `auto-subagent`, `auto-fast`, `auto-free`,
`fallback-free`, `openrouter-free`, `main-1m`, `main-128k`,
`heterion-router/auto`).

## Замеры

### До доверия (деплой ADR-029, 6 запросов через `auto`)

```
запрос 1: HTTP 200, отдал @cf/qwen/qwen3.8-27b
запрос 2: HTTP 401  (Token is invalid)
запрос 3: HTTP 404  (Not Found)
запрос 4: HTTP 404
запрос 5: HTTP 404
запрос 6: HTTP 200, отдал @cf/qwen/qwen3.8-27b
```

**4 провала из 6.** Причина: research-приоритеты (360 очков у `frontier`)
подняли модели, которых площадки не отдают, в голову лестницы; 404 по
контракту I-12 модель не штрафует — мёртвый кандидат оставался первым в
каждом запросе, бюджет попыток (24) съедался мёртвыми моделями.

Проверка качества данных: в топ-50 лестницы по capability-данным успешных
ответов в `call_logs` было **7**.

## Что дальше

- **Vision-эстафета** (дешёвая vision-модель описывает картинку → сильная
  модель работает с текстом) — направление владельца, в ADR-030 §«направления»
  не реализовано: нужен промежуточный шаг, меняющий контракт запроса.
- **Доверие растёт с использованием**: чем больше роутер говорит с моделью,
  тем выше её место; новые модели входят в оборот постепенно.
- **Чистка `call_logs` убирает доверие** — модели снова становятся
  недоказанными.
