# ADR-026 — Режим «только бесплатно» и адрес Cloudflare Workers AI

- **Статус:** принято 2026-11-15
- **Заменило:** часть соглашений ADR-021 (перечень моделей agentrouter) — уточнено,
  но не отменено.

## Контекст

Владелец объявил режим: **платить нельзя, денег нет**. Это не «пополнить
позже», а жёсткое ограничение на ближайший горизонт: роутер должен работать
на бесплатных путях и не обещать моделей, за которые нельзя заплатить.

Из этого следует два разных правила, и их важно не смешивать.

1. **Подключение без денег** (аккаунт площадки жив, баланс 0) — провайдер
   отключается целиком: `PATCH /api/connections/{id}` с `{"is_active": false}`.
   Ключ сохраняется, включение обратно — одна правка.
2. **Модель, за которую нельзя заплатить внутри живого провайдера** —
   модель убирается из реестра, потому что каталог должен перечислять то,
   чем роутер может ответить.

Исключение — модель, которая **есть на площадке**, но недоступна из-за
внутреннего лимита самой площадки: `agentrouter/gpt-6-astra` отвечает
`402 Budget pool quota has been exhausted. Please ask an administrator to
increase the limit`. Это не наш счёт и не наш лимит, поэтому модель остаётся
в реестре (контрактный тест `agentrouter::the_registry_names_the_models_the_platform_actually_serves`
требует именно список площадки), а клиент получает честную ошибку
площадки.

## Решение

### Отключённые подключения (баланс 0)

| провайдер | ответ площадки |
|---|---|
| `upstage` | 403 `API key suspended due to insufficient credit` |
| `cline` | 402 `Insufficient balance. Your Cline Credits balance is $0.00` |
| `xai` | 403 `Your newly created team doesn't have any credits or licenses yet` |
| `novita` | 403 `NOT_ENOUGH_BALANCE` |
| `dahl` | 401 `invalid_api_key` |
| `ai21` | 410 — endpoint выведен из обслуживания |

Изменение `is_active` **требует рестарта шлюза**: бэкенды строятся на старте,
в ответе `PATCH` приходит `restart_required: true`. После рестарта модели
этих провайдеров уходят из каталога (565 → 519 моделей).

### Модели, убранные из реестра

- `bazaarlink` — 125 из 126: аккаунт без баланса, площадка отвечает
  `402 … you can only afford 0`. Остался `auto:free` (200). Полный живой
  список площадки сохранён вне репозитория
  (`~/.local/share/camoufox/state/cf-…`-подобные снимки), вернуть модели
  можно одной правкой реестра после пополнения.
- `mistral/mistral-large-latest` — 403 `tier_not_allowed`: модель не входит
  в тариф аккаунта (Free). Остальные модели mistral бесплатны и остались
  (429 у части — rate limit бесплатного тира, не деньги).

### Cloudflare Workers AI

**В чём была проблема.** В реестре стоял
`base_url = https://api.cloudflare.com/client/v4/accounts` — это листинг
аккаунтов (GET), а не инференс. Даже с верным токеном оттуда брать нечего,
и `resolve_chat_url` превращал адрес в `…/accounts/chat/completions`.
Инференс Workers AI лежит по адресу
`https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/v1/chat/completions`.

**Аккаунтный идентификатор.** `account_id` принадлежит аккаунту оператора, а
не провайдеру, — в статическом реестре ему не место. Реестр несёт
плейсхолдер:

```
https://api.cloudflare.com/client/v4/accounts/{env:HETERION_ROUTER_CLOUDFLARE_ACCOUNT_ID}/ai/v1
```

Шлюз раскрывает `{env:ИМЯ}` из окружения (`expand_placeholders` в `main.rs`).
**Незакрытый плейсхолдер — это отсутствие провайдера, а не его поломка:**
`provider_base_url_from` возвращает `None`, провайдер не регистрируется и
попадает в отчёт о не обслуживаемых. Половина заполненного адреса дала бы
непонятный 404 вместо честного «не настроено».

**Токен.** Проверены оба типа:

| тип | префикс | account-эндпоинты |
|---|---|---|
| User API Token | `cfut_…` | `Authentication error` — площадка их не принимает |
| Account API Token | `cfat_…` | работают |

Нужен **аккаунтный** токен (`cfat_`) с разрешением `Account.Workers AI`
(Edit). Создаётся только в дашборде (API для выпуска токенов у Cloudflare
нет): `dash.cloudflare.com/<account_id>/api-tokens` → Create Token → Start
from scratch → permission group «Workers AI» → Edit → Review token →
Create token.

**У оператора два аккаунта Cloudflare.** `account_id` из истории URL
дашборда принадлежал второму; аккаунт оператора — `7cee0416…`. Токен,
созданный в профиле (`cfut_`), на аккаунтных эндпоинтах не работает.

**Бесплатный тариф.** Workers AI даёт 10 000 нейронов в сутки (Workers Free
и Workers Paid). В живой выдаче `GET /accounts/{id}/ai/models/search` — 75
моделей, из них 40 текстовые; **на Free-плане отвечают 24**, остальные
отвечают «not available on the Workers Free plan» (нужен платёжный метод).
В реестр записаны именно 24 проверенных: перечень берётся из площадки и
проверяется живым вызовом, а не по памяти.

## Последствия

- Каталог роутера перечисляет только то, чем он может ответить.
- Восстановление платёжных путей — одна правка (включить подключение,
  вернуть модели в реестр), ключи и снимки каталогов сохранены.
- `agentrouter/gpt-6-astra` в реестре остаётся: модель на площадке есть,
  исчерпан её бюджетный пул — это не наш лимит.
