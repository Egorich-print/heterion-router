# ADR-015 — Combo active flag for archiving

Дата: 2026-10-14 · Статус: принято (реализовано в рабочем дереве поверх `51dfe6d`).

## Контекст

В базе данных хранятся 8 комбо, из которых 2 имеют пустой массив моделей (`vivanta-auto` и `vivanta-deepseek` с `"models": []`). 
Эти комбо не могут быть использованы в маршрутизации потому что функция `parse_combo` возвращает `None` для комбо без моделей.
Однако до настоящего времени не было явного способа помечать комбо как архивные/неактивные без удаления данных из базы данных.

Пользователь явно указал: "Ничего не удалять без необходимости" и "Мёртвые комбо убрать из активного выбора OpenCode либо перевести в архивное/неактивное состояние. Сохранять возможность восстановления."

## Решение

1. **Добавить поле `active INTEGER NOT NULL DEFAULT 1` в таблицу `combos`**:
   - Значение 1 означает активное комбо (можно использовать в маршрутизации)
   - Значение 0 означает архивное/неактивное комбо (хранится в БД но не используется в маршрутизации)
   - Значение по умолчанию 1 обеспечивает обратную совместимость

2. **Обновить структуру `ComboRow`** в `repos.rs` чтобы включать поле `active`

3. **Обновить все функции работы с комбо** в `repos.rs`:
   - `get_combo`, `get_combo_by_name`, `list_combos` → включают поле `active` в SELECT
   - `list_active_combos` → новая функция которая возвращает только комбо где `active = 1`
   - `upsert_combo` → включает поле `active` в INSERT/UPDATE
   - `update_combo_meta` → обрабатывает поле `is_active` в `ComboMetaPatch`

4. **Обновить шлюз и админ панель** на использование `list_active_combos` вместо `list_combos`:
   - В `admin.rs`: заменить вызовы `list_combos` на `list_active_combos`
   - В шлюзе: аналогичная замена где используется список комбо

5. **Архивировать существующие пустые комбо** через обновление их статуса на `active = 0`:
   - `vivanta-auto` и `vivanta-deepseek` помечаются как неактивные
   - Данные сохранены в БД, их можно восстановить установив `active = 1`

## Следствия

- **Обратная совместимость**: все существующие данные остаются валидными
- **Явное управление архивацией**: комбо можно включать/выключать без удаления данных
- **Производительность**: роутинг и админ панель работают только с активными комбо
- **Восстановимость**: архивные комбо легко восстановить изменив флаг на активный
- **Соответствие требованиям**: ничего не удалено, мёртвые комбо переведены в неактивное состояние
