# docs/ — индекс

Документация Heterion Router. Корень репозитория
(`README.md`, `AGENTS.md`, `STATUS.md`, `CHANGELOG.md`) остаётся плоским: там
живёт то, что читают агенты и CI на первой странице.

| Раздел                    | Что внутри                                                                 |
| ------------------------- | -------------------------------------------------------------------------- |
| `docs/adr/`               | Решения: контекст → решение → следствия. Индекс — `docs/adr/README.md`.      |
| `docs/research/`          | Отчёты об исследованиях. Исторические, не спецификация.                       |
| `docs/history/`           | Frozen upstream JS material OmniRoute — не история Rust-порта (ADR-008 §8).  |
| `docs/MISSION-2026-10.md` | План миссии: objective, workstreams, DoD, тестовые пороги, stop/go.          |
| `docs/ROADMAP-2026-10.md` | **План развития по итогам аудита 2026-10**: M0…M7, ID из отчётов, effort/риск, Stop/go. |
| `docs/ROADMAP-2026-09.md` | Дорожная карта по периодам (предыдущая; приоритеты заменены на 2026-10).            |

## Правила

- ADR не переписывается задним числом: новое решение — новый файл, старое
  получает addendum. Список отклонённых/отложенных решений — в
  `docs/adr/README.md`.
- Отчёты в `research/` — свидетельство на момент даты. Если код изменился,
  обновляют `STATUS.md`, а не отчёт.
- Числа в документах должны воспроизводиться: перед тем как написать «N тестов»,
  прогони `cargo test --workspace` и посчитай `test result:` строки.
