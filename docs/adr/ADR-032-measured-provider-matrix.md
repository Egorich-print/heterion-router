# ADR-032 — Матрица провайдеров: измеренная причина вместо заявления

- **Status:** accepted
- **Date:** 2026-11-16
- **Relates to:** ADR-025 (веб-исполнители), ADR-026 (режим «только бесплатно»),
  ADR-027 (единый пул Switchyard)

## Context

Реестр (`crates/heterion-router-providers/registry.json`) описывает 281
провайдера, но живой каталог — 415 моделей у 41 провайдера. Разница
объяснялась четырьмя причинами, и все четыре были **заявлениями реестра**,
а не измерениями:

- формат или исполнитель не реализован в шлюзе (7 провайдеров);
- веб-исполнитель без адаптера у драйвера (3);
- формат есть, ключ не нужен, бэкенда нет (17);
- формат реализован, но нет ключа (212).

Живые пробы 2026-11-16 показали, что заявление `auth_type: none | optional`
часто неверно:

| площадка | ответ без ключа | что это значит |
|---|---|---|
| `api.naga.ac` | `401 authentication_required` | ключ нужен — реестр врал |
| `hermes.ai.unturf.com` (uncloseai) | `401 public beta is closed` | площадка закрыта |
| `g4f.space/api/*` (5 провайдеров) | `402 No cake credits` | нужны кредиты или аккаунт |
| `clovastudio.stream.ntruss.com` | `401` (корейский конверт) | нужен ключ Naver |
| `api2.cursor.sh` | `404 Route POST:/… not found` | чат-маршрута нет вовсе |
| `api.deepai.org` | `404` (HTML) | чат-API нет; модель `text2img` |

## Decision

**Причина провайдера — измеренный ответ, а не запись в реестре.**

1. **Новый модуль `crates/heterion-router-gateway/src/provider_status.rs`**:
   - `classify(status, body)` — ответ площадки → причина
     (`served`, `needs_key`, `credits_required`, `dead_endpoint`,
     `not_a_chat_api`, `unknown`);
   - `reason_for(facts)` — правило: структурный пробел (формат не
     реализован, нет адаптера) важнее измеренного, потому что ни ключ, ни
     кредиты не исправят отсутствующую реализацию;
   - `probe(...)` — один дешёвый запрос без ключа: спрашивает площадку,
     отвечает ли она.
2. **Пробы кэшируются** в новой таблице `provider_probes` (миграция `004`).
   Шлюз опрашивает keyless-площадки при старте; админ-API умеет перепроверить
   одного провайдера: `POST /api/providers/{id}/probe`.
3. **Keyless-проход** (`select_backend`): провайдер без ключа попадает в
   каталог **только** если проба доказала, что площадка отвечает без ключа.
   Провайдер в каталоге, который не может ответить, хуже отсутствующего
   (ADR-025).
4. **Веб-исполнители исключены из keyless-прохода и из проб.** Их «эндпоинт» —
   чат-страница: она отвечает `200` на любой POST, поэтому проба там не
   измеряет ничего, а ответ всё равно приходит из браузерного драйвера,
   которому нужен адаптер. Первая версия прохода это упустила и впустила в
   каталог `duckduckgo-web`, `deepseek-web` и `blackbox-web` без адаптеров.
5. **`GET /api/providers`** отдаёт у каждой записи `served`, `reason`,
   `models` и `last_probe`, а ключ `matrix` — весь реестр с теми же
   причинами. Старый список `providers` (то, что годится для формы ключа)
   сохранён без изменений.
6. **`scripts/provider_matrix.py`** прогоняет все площадки и пишет отчёт;
   пробу и классификацию делает сам шлюз, поэтому отчёт не может разойтись с
   тем, что видит админ-API.

## Что выведено из чат-реестра

Решение владельца (2026-11-16): провайдеры, у которых чат-API нет в
принципе, из чат-реестра уходят.

| провайдер | моделей | причина |
|---|---|---|
| `cursor` | 198 | `404 Route POST:/… not found` — нужен протокол клиента Cursor |
| `cursor-api` | 198 | то же (это модели редактора, а не площадки) |
| `deepai` | 1 (`text2img`) | генерация картинок, чат-API нет |
| `uncloseai` | 3 | `401 public beta is closed` — площадка закрыта |

Подключение `kiro=1` отключено (формат AWS CodeWhisperer шлюз не говорит);
ключ сохранён, как при отключении платного пути (ADR-026).

`agy`/`antigravity` и `clova-studio` остаются в реестре: по решению
владельца под них делаются бэкенды, и для этого нужен вход владельца в
Google и Naver.

## Consequences

- Матрица воспроизводима: `scripts/provider_matrix.py` даёт тот же ответ
  вчера и сегодня, а расходиться с админ-API не может.
- «Ключ не нужен» перестало быть ложным заявлением реестра.
- Каталог не растёт за счёт площадок, которые не отвечают: ключевой проход
  требует доказательства.
- Появился новый вид отказа, которого раньше не было: площадка, которая
  раньше молча отвечала `402`, теперь видна как `credits_required` — и по
  режиму «только бесплатно» просто не попадает в каталог.

## Contracts

`crates/heterion-router-gateway/tests/provider_status.rs` (6 контрактов) и
юнит-тесты модуля: классификация ответов, выбор причины, узость
keyless-прохода, исключение веб-исполнителей.
